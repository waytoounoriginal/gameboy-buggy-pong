# Gameboy Buggy Pong

My first game made for the Game Boy, written in C with GBDK 2020. It is very
buggy.

## About

A Pong implementation for the original Game Boy. The project was a learning
exercise for GBDK and constraints of the platform (limited memory, tile
based rendering).

## Structure

- `Pong/` - the game source

## Building

Compile with GBDK 2020, then flash the resulting ROM to a Game Boy cart or
run it in an emulator.
